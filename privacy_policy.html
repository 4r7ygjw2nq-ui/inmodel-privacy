INMODEL - Privacy Policy

Pinterest Automation Application | Last updated: May 2026

1. Who We Are

INMODEL is a women clothing brand selling on Wildberries marketplace. This application is operated by INMODEL for automating publication of product imagery to our official Pinterest business account.

Contact: anzhela.ostrouhova@gmail.com

2. What Data We Access

The App connects to Pinterest API v5 and accesses only:

  • Pinterest account information - username and account details for authentication
  • Pinterest boards - list of boards to publish pins to the correct board
  • Ability to create pins on INMODEL own boards only

The App does NOT access any data of third-party Pinterest users or followers.

3. How We Use Data

Data accessed through Pinterest API is used exclusively to authenticate our account, select boards, and create product pins with links to Wildberries product pages. We do NOT sell or share any Pinterest data.

4. Data Retention

The Pinterest access token is stored locally on the operator computer. No Pinterest data is stored in any external database or cloud service. The token can be revoked at any time from Pinterest app management dashboard.

5. Third-Party Services

  • Pinterest API v5 - policy.pinterest.com/privacy-policy
  • Wildberries Seller API - used to retrieve INMODEL own product catalog only
  • Google Drive API - used to access product photos in INMODEL own Drive folder only
  • OpenAI API - used to generate descriptive text and lifestyle images for pins

6. Security

Access tokens and credentials are stored locally and are not transmitted to any external server. The App runs entirely on the operator local machine.
